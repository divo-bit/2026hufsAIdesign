🎈 말랑말랑 영단어 모험 (Soft English Word Adventure)
어린이를 위한 귀엽고 직관적인 웹 기반 5분 기초 영단어 학습 및 퀴즈 애플리케이션입니다.
별도의 설치 없이 단 하나의 HTML 파일(index.html)만으로 동작하는 가볍고 빠르게 실행되는 단어 학습 서비스입니다.
✨ 주요 특징 (Key Features)
🃏 3D 플래시 카드 학습 모드
입체적인 카드를 터치/클릭하여 뒤집으면서 단어의 영어 표기와 한국어 뜻, 예문을 직관적으로 확인합니다.
어린이의 눈높이에 맞춘 귀여운 이모지 그림이 함께 제공됩니다.
🎮 재미있는 4지선다 단어 퀴즈 모드
제시된 뜻과 이모지를 보고 알맞은 영단어를 맞히는 흥미로운 퀴즈 게임을 제공합니다.
정답 시 신나는 애니메이션 효과 및 즉각적인 피드백을 제공합니다.
🔊 음성 지원 (TTS, Text-to-Speech)
Web Speech API를 활용하여 어린이가 영어 단어의 올바른 발음을 언제든 들어볼 수 있습니다.
📱 반응형 웹 UI & 아기자기한 디자인
모바일, 태블릿, PC 어디서나 보기 좋은 깔끔한 Tailwind CSS 기반 디자인을 제공합니다.
⚡ 단일 파일 실행 (Single-file App)
복잡한 빌드 과정이나 백엔드 서버 없이 브라우저에서 index.html 파일만 열면 바로 실행할 수 있습니다.
🛠️ 기술 스택 (Tech Stack)
Frontend: HTML5, JavaScript (ES6+)
Styling: Tailwind CSS (CDN), Custom CSS 3D Transforms
Icons & Fonts: Font Awesome 6, Google Fonts (Jua, Nunito)
Audio API: Browser Native SpeechSynthesis API
🚀 시작하기 (Getting Started)
1. 리포지토리 클론 (Clone)
git clone https://github.com/your-username/soft-word-adventure.git
cd soft-word-adventure


2. 실행 방법 (Run)
별도의 서버 설치가 필요 없습니다.
index.html 파일을 더블 클릭하여 웹 브라우저(Chrome, Edge, Safari 등)에서 실행하면 됩니다.
또는 VS Code의 Live Server 확장 프로그램을 이용해 간편하게 실행할 수 있습니다.
